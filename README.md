# Pretty-Links
Pretty Links Module for Joomla 5.4 & Joomla 6

Displays a row or list of links, each with an optional Font Awesome icon. Links can open in the same or a new window, and their text can be hidden on mobile while staying available to screen readers.

Joomla 4 sites: version 1.0.2 is the last release that supports Joomla 4.
